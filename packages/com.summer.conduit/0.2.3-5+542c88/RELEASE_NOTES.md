# Conduit 0.2.3

## 新功能
- 适配 xtheos 1.0.0 规范，支持 rootful、rootless、roothide 三越狱环境全架构（arm64 / arm64e）自动出包与编译壳导出。
- 单条消息载荷上限提升至 10MB，偏好存储单值上限提升至 1MB、单域上限提升至 10MB。

## 改进
- 守护进程与服务组件全面升级为原生 Xcode 多产物构建系统，支持目标依赖自动解析与符号防丢。
- 完善三环境动态库编译壳（Conduit.framework、Conduit.tbd、头文件与导出符号）。

## 修复
- 修复复杂并发通信场景下服务端连接断开重连时状态不同步的问题。
- 修复多 Target 组合出包时架构矩阵缺失的隐患。

## 升级与兼容性
- 向下兼容所有既有 Conduit 客户端 API，上层组件（如 harness）可直接无缝链接。
